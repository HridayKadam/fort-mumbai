# Fort, Mumbai

Hriday's miniature of Fort and Kala Ghoda — a small, soft isometric town in the browser.

## Deploy on Vercel

Import **this** repo (`HridayKadam/fort-mumbai`), not the big `tinytown` fork.

1. [vercel.com/new](https://vercel.com/new)
2. Import `fort-mumbai`
3. Framework: Other. Install and Build can stay empty. Output: `.`
4. Deploy. You get a `*.vercel.app` URL.

The original tinytown fork is hundreds of megabytes, so Vercel dies during clone. This repo is only the viewer plus Fort.
